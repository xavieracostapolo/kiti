# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment and personal attacks are not accepted.

Report unacceptable behaviour privately to the maintainer. A [private advisory](https://github.com/xavieracostapolo/kiti/security/advisories/new) is the private channel of this repository; use it for conduct reports too. Reports are handled confidentially.
